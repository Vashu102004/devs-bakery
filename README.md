- 🎞️ **Framer Motion** — Animations

- 🔍 **Lucide React** — Icons

## 🚀 Getting Started

### Prerequisites
- Node.js 18+
- npm

### Installation

```bash
# Clone the repository
git clone https://github.com/Vashu102004/devs-bakery.git

# Go into frontend folder
cd devs-bakery/frontend

# Install dependencies
npm install

# Start development server
npm run dev
```

Open http://localhost:5173 in your browser 🎉
